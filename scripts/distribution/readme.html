接入现有项目

node /path/to/bundle/install.mjs --preset singleplayer --target /path/to/my-game

安装器校验摘要并补齐所需的内部依赖。预设为 core、singleplayer、client、server。详情见本地分发与版本维护。

保存与校验

保留目录结构；manifest.json 记录版本与源码来源，SHA256SUMS 记录包摘要。创建独立游戏请阅读快速上手。
