DEVELOPER GUIDE

资源、音频与保存

从可运行代码开始，理解模块边界与完整接入流程。

本指南使用当前 application 入口。资产传输、Web Audio 和存储的浏览器适配属于应用装配；引擎负责类型、共享、取消与所有权，不在导入时创建隐式全局设备。先阅读 应用总览，完整签名见 API 索引。

资源组与租约

defineAssetGroup 支持 image、atlas、audio、json。图片传输返回 {source,width,height}；音频返回 ArrayBuffer；JSON 返回待 parse 的原始数据；atlas 的帧表在声明中给出。JSON parse 必须同步、验证并返回普通数据。optional:true 的条目失败不会让整个组失败，读取可能为 undefined。

下面的示例新增一个 JSON 资源和返回纯数据的辅助函数：

src/assets/data/rules.json
{ "target": 10 }
src/assets/data/game-data.ts
import {
  defineAssetGroup,
  type AssetContext,
  type AssetGroupProgress,
} from '@xiaobaibaifqy/jingchuanchu-app/application';
import type { CancellationSignal } from '@xiaobaibaifqy/jingchuanchu-core';

export const GameData = defineAssetGroup({
  name: 'game-data',
  entries: {
    rules: {
      kind: 'json',
      url: new URL('./rules.json', import.meta.url).href,
      parse(value: unknown) {
        if (
          !value ||
          typeof value !== 'object' ||
          !('target' in value) ||
          typeof value.target !== 'number' ||
          !Number.isSafeInteger(value.target) ||
          value.target <= 0
        )
          throw new Error('Invalid target');
        return { target: value.target };
      },
    },
  },
});

export async function loadTarget(
  context: { assets: AssetContext; signal: CancellationSignal },
  onProgress: (progress: AssetGroupProgress) => void = () => {},
) {
  const lease = await context.assets.load(GameData, { signal: context.signal, onProgress });
  try {
    context.signal.throwIfAborted();
    return lease.get('rules').target;
  } finally {
    lease.release();
  }
}

从页面事件或 onMount 启动异步 loadTarget(context)，将结果写入 signal 前检查页面取消/请求代次，错误和进度由页面显示。不要把异步请求直接放进 computed、async effect 或 async setup。onProgress 的 completed/failed/pending 是条目数量，不是下载字节百分比；同步进度回调也要避免抛出无归属异常。

默认参考模板的 createBrowserAssetTransport 仅接图片/图集与音频字节，并不自动获取 JSON。使用上述资源时，需要为 JSON 扩展传输，不能只声明 group 就期待 fetch。新增：

src/app/game-asset-transport.ts
import type { AssetTransport } from '@xiaobaibaifqy/jingchuanchu-app/application';
import { createBrowserAssetTransport } from './asset-transport.js';

export function createGameAssetTransport(): AssetTransport {
  const browser = createBrowserAssetTransport();
  return {
    async load(entry, signal) {
      if (entry.kind !== 'json') return browser.load(entry, signal);
      signal.throwIfAborted();
      const abort = new AbortController();
      const off = signal.subscribe(() => abort.abort(signal.reason));
      try {
        const response = await fetch(entry.url, { signal: abort.signal });
        if (!response.ok) throw new Error(`Resource HTTP ${response.status}`);
        const raw: unknown = await response.json();
        signal.throwIfAborted();
        return raw;
      } finally {
        off();
      }
    },
    release(entry, raw) {
      if (entry.kind !== 'json') return browser.release?.(entry, raw);
    },
  };
}

将 AppConfig.assets.transport 设为 () => createGameAssetTransport()，下面主题示例提供完整配置。引擎 CancellationSignal 使用 subscribe/throwIfAborted，不是 DOM AbortSignal；fetch 需像上面一样桥接 AbortController。

load 返回的 lease 归实际组件/页面/场景 owner；owner 退出或显式 release 后不能再 get。单方取消不破坏其他持有者；晚到资源由传输/服务按归属释放。只需纯数据时可复制/读取后立即 release；CanvasImageSource 仍在使用时必须保留所属租约，不能先释放再绘制。默认并发为 4，可用 assets.concurrency 设置正整数。

通过语义键替换主题资源

在项目中执行一次 npm run generate -- theme forest --extends default，然后编辑生成文件。下面用已存在的 dusk 素材说明图集到普通图片的替换；实际项目可换成自己的资源文件并保留许可：

src/themes/forest/forest-theme.ts
import { extendTheme } from '@xiaobaibaifqy/jingchuanchu-app/application';
import { DefaultTheme } from '../default/default-theme.js';

export const ForestTheme = extendTheme(DefaultTheme, {
  name: 'forest',
  tokens: { accent: '#8cd992' },
  assets: {
    'game.collectible': {
      kind: 'image',
      src: new URL('../dusk/assets/star.svg', import.meta.url).href,
    },
  },
});
src/app/app-config.ts
import { defineApplication, provideService } from '@xiaobaibaifqy/jingchuanchu-app/application';
import { AppShell } from './app-shell.js';
import { AppRoutes } from './app-routes.js';
import { GameStorage } from '../game/preferences/settings-storage.js';
import { ForestTheme } from '../themes/forest/forest-theme.js';
import { createGameAssetTransport } from './game-asset-transport.js';
import { createWebAudioDriver } from './web-audio-driver.js';

export const AppConfig = defineApplication({
  root: AppShell,
  routes: AppRoutes,
  theme: ForestTheme,
  assets: { transport: () => createGameAssetTransport(), concurrency: 4 },
  audio: { driver: () => createWebAudioDriver(), maxEffects: 8 },
  providers: [provideService(GameStorage)],
});

组件/场景仍用 context.useTheme(DefaultTheme) 取得选定主题，DefaultTheme 是语义键的契约；不要因选用 ForestTheme 就逐个改调用方。resolve(key) 只解析描述，不加载；load(key) 返回包含 image、frame（图集区域时）、fallback、diagnostic、release 的租约。覆盖加载失败只尝试最初默认资源一次；取消不回退。普通图替换图集区域会整体替换，不残留 frame。

DOM 的 img 可用 resolve('ui.pause').src；Canvas 用 load 后的 image.source 和可能的 frame。二者来自同一资源映射，但源图尺寸不决定碰撞或显示几何。token 只支持 string/number，安装为应用根上的 --jcc-* CSS 变量；布局放组件 CSS/Less。extendTheme 只能覆盖基础契约已有键和兼容的 token 类别。当前是开发配置选择，不提供玩家上传或运行时换肤入口。

音频解锁与播放

audio 配置必须配有 assets；driver 是同步工厂，但 unlock/decode/start 可异步。createWebAudioDriver 是参考项目 src/app 中的实现，不是引擎导出的全局函数。导入应用时不会自动创建/解锁 AudioContext。

页面的真实点击事件中先调用 context.audio.unlock()，再 await；不要先请求文件或经过其他 await 后才开始解锁。根据返回 status 判断 ready/blocked/failed/cancelled。设备 ready 后调用 playEffect(GameSounds,'collect') 或 playMusic(group,key)，只允许音频键。play 返回 played/blocked/failed/cancelled，played 含 playback，可 stop；played 不代表静音设备实际可听。

单轨音乐默认循环，替换失败保留旧曲。音效默认上限 16，默认 drop-new，可配置 drop-oldest；参考模板设为 8。未解锁不加载、不积压待播音效。音量范围 0—1，master×music/effects 得到实际增益；setMuted 不覆盖保存的音量。

context.audio 归组件/页面，scene.audio 归场景；暂停/停用时取消待播并停止音效，音乐按所属活动态暂停，自动恢复不覆盖手动 pauseMusic。离页停止所属声音，不停止其他 owner 的声音。全局音量与解码缓存归应用。默认偏好绑定由 main.ts 的 bindAudioPreferences 完成；只更改 UI Store 而未绑定音频服务不会改变设备输出。

实际接线见 src/pages/play/play-page.ts 的 unlockAudio/playSound、src/assets/audio/game-sounds.ts 和 src/app/web-audio-driver.ts。声音素材说明与生成命令在 assets/audio/ASSETS.md，分发时保留许可。

显式白名单保存与恢复

以下延续 组件教程 的 ScoreStore。保存服务只处理数据，不会自动恢复 Store：

src/game/session/score-save.ts
import { defineSave } from '@xiaobaibaifqy/jingchuanchu-app/application';
import type { Token } from '@xiaobaibaifqy/jingchuanchu-ecs';
import { ScoreStore } from './score-store.js';

type ScoreState = typeof ScoreStore extends Token<infer T> ? T : never;
export const ScoreSave = defineSave<ScoreState, { score: number }>({
  key: 'score-demo',
  version: 1,
  select: (store) => ({ score: store.state.score() }),
  parse(value: unknown) {
    if (
      !value ||
      typeof value !== 'object' ||
      !('score' in value) ||
      typeof value.score !== 'number' ||
      !Number.isFinite(value.score) ||
      value.score < 0
    )
      throw new Error('Invalid score');
    return { score: value.score };
  },
  restore: (store, data) => {
    store.actions.setScore(data.score);
  },
});

为 bonus 页增加页面私有操作文件：

src/pages/bonus/score-storage.ts
import { signal, type ComponentContext } from '@xiaobaibaifqy/jingchuanchu-app/application';
import { ScoreStore } from '../../game/session/score-store.js';
import { ScoreSave } from '../../game/session/score-save.js';
import { GameStorage } from '../../game/preferences/settings-storage.js';

export function useScoreStorage(
  context: Pick<ComponentContext<{}, {}, {}>, 'signal' | 'useStore' | 'useService'>,
) {
  const store = context.useStore(ScoreStore),
    storage = context.useService(GameStorage);
  const busy = signal(false),
    storageNotice = signal('');
  const persist = async (load: boolean) => {
    if (busy() || context.signal.aborted) return;
    busy.set(true);
    const result = load ? await storage.load(ScoreSave) : await storage.save(ScoreSave, store);
    if (context.signal.aborted) return;
    if (result.status === 'loaded') {
      ScoreSave.restore(store, result.data);
      storageNotice.set('已读取已提交得分，当前编辑草稿保留。');
    } else storageNotice.set(result.status === 'saved' ? '已保存。' : `未完成：${result.status}`);
    busy.set(false);
  };
  return { busy, storageNotice, save: () => persist(false), load: () => persist(true) };
}

在 bonus-page.ts 导入 useScoreStorage，在 setup 中调用 const persistence = useScoreStorage(context)，并在返回对象中加入 ...persistence。这是 setup 返回值的展开，不是组件元数据的展开。模板追加以下按钮：

html
<button type="button" :disabled="busy" @click="save()">保存已提交得分</button>
<button type="button" :disabled="busy" @click="load()">读取得分</button>
<p role="status">{{ storageNotice }}</p>

操作保存的是已提交 Store 数据，不是未提交的数字草稿；读取恢复已提交值，草稿由用户选择“恢复已提交得分”才更新。busy 阻止同页并发读写，离页后不恢复旧结果。需要允许读取期间继续改业务值时，还应比较请求代次/编辑版本，参考设置页已示范。

默认 GameStorage 用 SaveService 的惰性 localStorage 包装；可用 provideService(GameStorage, factory) 替换成注入 StorageAdapter 的 SaveService。无需浏览器时，注入异步 get/set/remove 的内存适配。defineService 的 factory 必须同步返回服务，异步工作放在方法里；清理登记到 factory 的 scope，不依赖 GC 关闭资源。

save 返回 saved/invalid/unavailable；load 返回 loaded/empty/corrupt/incompatible/unavailable。select/parse/migrate 同步，只接受严格有限 JSON 数据；不能 JSON.stringify 整份 Store。migrate 明确从已知旧版本转换为当前 DTO，坏档和不兼容档不自动删除/改写。reset 只删除该定义在当前命名空间下的记录。

默认键为 jcc:save:anonymous:encodeURIComponent(key)。用户隔离时创建固定 namespace:{kind:'user',userId} 的 SaveService；更换 namespace 要创建新服务，不修改旧实例入参。读取结果在业务层显式 restore：编辑中/离页/账号变化后不要让晚到结果覆盖当前状态，高分等可采用显式合并。参考设置和进度页已示范这些处理。

可选账号与权限

默认单机不依赖账号。需要时为应用注册 AuthService，注入 AuthProvider 的 restore/login/logout/decode；客户端展示的 session 只包含已验证用户数据。context.useService 读取服务，调用 ensureSession() 按需恢复，login/logout 均检查判别状态；失败不同于匿名，退出时本地清理不同于服务端撤销确认。restore 是 Provider 的方法，不是 AuthService 的公开方法。

AccessService 用 permissions 选择器和有限权限键提供 can/check；路由在 meta.access 声明 'public' 或 {session:'required',all/any}。使用 createAccessGuard 接到 AppConfig.router.guards，再用 bindAccessRouter 让账号变化取消受保护页面；登录后 returnTo 用 resolveAccessReturnTarget 校验。redirect 的登录/无权限页必须显式 public，缺失策略不会被当作公开。

完整同源 HTTP Provider、协议、内存测试后端与部署契约见 账号适配示例，配置细节见 权限规格。引擎不提供账号数据库；服务端仍需校验每个受保护请求，不能把前端隐藏按钮或路由守卫当作服务器授权。凭据不进入 signal/Store/URL/默认存档。
