ENGINEERING HANDBOOK

当前版本

记录当前与历史版本的功能、升级方式和验证范围。

0.6.0（2026-11-11）

  • 新增可选 WebGL 2 后端，支持静态精灵、图集、矩形与圆形。Canvas 2D 仍为默认。
  • WebGL 2 按相邻同纹理项合批，保留叠放顺序，并可在上下文恢复后重建绘制资源。
  • Windows Chrome 与 RTX 3060 Ti 上，单图集 10,000 精灵场景实测约 58.5–59.0 FPS，Canvas 2D 为 17.1–17.3 FPS。普通负载约 60 FPS。

接入和回退步骤见渲染指南。完整测量口径见验收记录。

0.5.0 正式版（2026-11-07）

生产级落地版本。在前轮性能迭代基础上补齐开发者工具与测试覆盖，不改现有架构与公开 API。新增 bulkQuery API 用于只读热路径迭代、Transform 帧缓存用于渲染与碰撞检测共享、PerformanceMonitor 运行时性能采集（<1ms/帧开销）、createPerfPanel 可选调试面板（通过 defineApplication({ debug: { perfPanel: true } }) 启用）。桌面浏览器测试矩阵涵盖 Chromium/Firefox/WebKit 三引擎，Node 端内存耐久测试 2.09 MB 低于 10 MB 阈值。实际性能提升：bulkQuery 15-18%（迭代器协议开销降低了计划的 55% 目标）；渲染管线约 5%；碰撞与输入微优化单独衡量。详见 CHANGELOG.md 和 性能基准。

应用模型

application 入口集中提供原生 TS/HTML/CSS 或 Less 三文件组件、响应式状态、输入/输出/model、Store、服务与页面路由。

网页游戏能力

GameCanvas 接管页面内场景、固定步、输入和清理。资源组与主题管理语义图片，音频能力显式解锁，存档定义显式选择字段并按版本解析。认证与权限可选接入。

项目与交付

默认参考模板覆盖首页、选关、游玩、暂停、设置、结算与重开。CLI 支持 create、generate、add 与 check；本地套件包含包、模板、示例与独立 HTML 手册。版本及依赖以根和各包的 package.json 为准。

验证限制

实际浏览器、设备音频、后台恢复与性能按人工验收项记录。详见检查与验收边界。
