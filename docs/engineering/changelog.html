ENGINEERING HANDBOOK

当前版本

0.5.0-rc.1 · 网页 2D 游戏应用框架。

应用模型

application 入口集中提供原生 TS/HTML/CSS 或 Less 三文件组件、响应式状态、输入/输出/model、Store、服务与页面路由。

网页游戏能力

GameCanvas 接管页面内场景、固定步、输入和清理。资源组与主题管理语义图片，音频能力显式解锁，存档定义显式选择字段并按版本解析。认证与权限可选接入。

项目与交付

默认参考模板覆盖首页、选关、游玩、暂停、设置、结算与重开。CLI 支持 create、generate、add 与 check；本地套件包含包、模板、示例与独立 HTML 手册。版本及依赖以根和各包的 package.json 为准。

验证限制

实际浏览器、设备音频、后台恢复与性能按人工验收项记录。详见检查与验收边界。
