ENGINEERING HANDBOOK

检查与验收边界

区分类型、Node、打包和真实设备的证据，按改动选择检查。

选择必要的检查

改动 对应命令
文档 npm run docs:check，检查 HTML、站内链接、锚点、导航和 API 覆盖。
类型及运行时 npm run typecheck 与相关 Node 测试。
应用运行时 npm run test:app。
模板与项目结构 npm run check:templates、npm run test:project。
独立包 npm run test:packages。
生成交付套件 npm run dist:release。
Node 分发验证 npm run test:distribution:node，会重新构建套件。

浏览器验收

test:2d 和 test:distribution 会启动浏览器，仅在明确安排时运行。实际游玩、中文输入/焦点、触控/导航历史、设备音频解锁、后台恢复与性能仍需按 tasks/acceptance.md 单独验收。

结果应准确命名

类型检查不代表运行通过；Node DOM 和注入驱动不代表真实设备通过；静态构建不代表实际游玩通过。性能报告应包含同环境基线、测量方法、原始数据和限制。

文档站验证

文档检查使用 HTML 解析器与当前源码导出信息，不启动浏览器。它验证本地文件、资源、页内目标、搜索记录和 API 覆盖，不验证页面像素布局、剪贴板权限或实际点击体验。
