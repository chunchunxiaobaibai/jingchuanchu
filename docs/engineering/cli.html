ENGINEERING HANDBOOK

CLI 与项目配置

create、generate、add 与 check 的完整命令与边界。

创建项目 · create

jingchuanchu create ./my-game --preset singleplayer --style css --bundle /path/to/bundle
参数 含义
directory 不存在或为空的目标目录。
--preset core / singleplayer / client / server。网页游戏从 singleplayer 开始；client 增加网络依赖但不会自动连接。
--style css / less，默认 css。
--bundle 含 manifest.json 与 packages/ 的配套套件目录，复制依赖到 vendor。

CLI 不自动安装依赖或启动服务。创建后进入项目执行 npm install。core/server 不生成网页 UI。当前默认浏览器 profile 为 application。

生成业务文件 · generate

在游戏目录中运行，可通过 --project 显式指定项目根目录：

npm run generate -- page bonus --route /bonus
npm run generate -- component hud --page bonus
npm run generate -- component icon-button --shared
npm run generate -- scene bonus --page bonus
npm run generate -- store score --domain session
npm run generate -- theme forest --extends default
类型 归属及行为
page 写入 pages/name/name-page 三文件，需 --route；静态分析并注册懒路由。
component 必须选择 --page 或 --shared；生成三文件，父组件需自行注册和引用。
scene 需 --page，生成页面旁的 name-scene.ts，自行交给 GameCanvas。
store 需 --domain，生成 game/domain/name-store.ts。
theme 生成 themes/name/name-theme.ts；--extends 指定基础主题，需手动在应用选择。

名称须为 kebab-case。组件和页面可用 --style css|less 单次覆盖。已有同名业务、等价路由、不可静态修改的路由表或越界路径会报错；请修正冲突或按诊断手动接入。

安装能力 · add

npm exec -- jingchuanchu add --modules assets,net --bundle /path/to/bundle
npm install
npm run check

--modules 和 --all 二选一；--all 也包含服务端包。安装器校验摘要、解析内部依赖闭包、将 tgz 保存到 vendor 并写相对 file 依赖，tooling 放 devDependencies。它不自动安装或更新锁文件；同名不同字节文件会拒绝覆盖。

检查项目 · check

jingchuanchu check
jingchuanchu check /path/to/my-game
npm run check
npm run build

CLI check 检查项目配置、目录边界、组件资源与模板表达式。游戏脚本 npm run check 还执行 TypeScript，build 再调用 Vite。各项检查不能相互替代。

jingchuanchu.json

{
  "schemaVersion": 2,
  "profile": "application",
  "preset": "singleplayer",
  "style": "css",
  "paths": {
    "app": "src/app",
    "pages": "src/pages",
    "game": "src/game",
    "components": "src/components",
    "themes": "src/themes",
    "account": "src/account"
  }
}

paths 缺省为 src 下的同名目录，必须在项目内、不重叠，不允许通过符号链接越界。声明可选路径不会生成空目录。修改配置不会自动搬移文件或重写导入。

Vite 插件

import { defineConfig } from 'vite';
import { jingchuanchu } from '@xiaobaibaifqy/jingchuanchu-tooling/vite';

export default defineConfig({
  plugins: [jingchuanchu()],
});

插件识别具名导入的组件工厂，将定义与同名 HTML、CSS/Less 关联，并把表达式诊断映射回原模板。不要手写内部编译字段。配套文件变化当前可触发整页重载，不保证保留组件状态。
