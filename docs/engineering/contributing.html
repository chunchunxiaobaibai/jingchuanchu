开始开发

npm ci
npm run typecheck

阅读当前 SPEC.md、模块契约与任务状态。游戏玩法保存在独立项目，引擎包只提供通用能力。

组织变更

说明具体触发条件、修改后的行为与影响范围。新增能力同步更新本站指南及 API 使用契约，修复核心行为或具体缺陷时增加直接回归。常量、目录或低影响文档修改采用必要静态检查。

修改文档

直接编辑对应 HTML 的 article[data-doc-content] 区域。新增页面时在 scripts/docs/pages.json 登记 path、title、section 和 description，并在 scripts/docs/site.mjs 配置导航，运行以下命令同步站点： 

npm run docs:build
npm run docs:check
npm run docs:dev

文档预览服务只监听本机，不自动打开浏览器。可直接打开 docs/index.html 离线阅读；搜索、导航和主题功能都使用本地资源。

反馈与交付

问题报告包含提交号/套件版本、Node/npm、系统及浏览器版本、最小复现、预期与实际结果。提交源码、文档与必要锁文件，交付时列出实际检查和未验证项。合并、推送、Release 与 npm 发布是分别授权的操作。

布局参考

参考 Vue API 参考的分类与过滤方式，以及快速上手的分步阅读结构。本站直接使用 HTML、CSS 与原生 JavaScript，实现固定 PC 布局。
