# 验证记录

- `npm run build`：严格 TS 类型检查、Vite 网页构建、Node 服务端编译通过。
- `npm test`：25 项测试通过，包含真实 WebSocket 集成、10 人容量、模块生命周期与单机游戏逻辑。
- `npm run test:e2e`：3 项 Chromium 浏览器测试通过，独立客户端间画布同步、答案隔离、猜词计分、下一回合、退出和 320px 窄屏布局均验证；单机玩法在阻断 WebSocket 时运行。
- 独立包验证：两种临时外部项目分别离线安装内核包、单机功能组合，编译并执行 TS，确认 ws、zod 和网络包未安装。
- `npm run build:singleplayer`：仅静态单机网页构建通过，不需要游戏服务器。
- 静态预览验证：游戏服务器未启动时，单机页面收集得分成功，WebSocket 连接数为 0，页面无异常。内核包消费项目只使用 ES2022 类型库，无需 DOM 类型。
- `npm run format:check`：通过，源文件统一格式。
- `npm audit --omit=dev`：运行依赖无已知漏洞。

审查补充了实体的 World 归属校验、系统内销毁的中断行为、旧取消订阅函数的重复调用保护、延迟命令中销毁后的中断，并为这些情况添加了回归测试。
网络传输层通过回调报告错误，不依赖游戏消息结构；连接超出总消息频率时关闭，客户端同步请求有去重保护。
0.2.0 新增包边界检查、服务回滚、手动暂停保持、网络启停和指针捕获释放测试；单机与联机均通过公开引擎入口组装。

0.2.1 分发套件验证通过：8 个 tgz 的 README/LICENSE/ESM/声明与文件白名单、归档及包 SHA-256、文档链接、按需安装和不写入的 dry-run、损坏包拒绝、无 DOM 内核消费、三个可运行文档示例、独立 TS/Vite 模板的编译和浏览器操作、真实 ping/pong 服务端与客户端。所有消费者从临时目录内解压的分发包安装，未引用工作区源码。

0.3.0 镜川初发布候选完成包名迁移，构建、25 项测试、3 项浏览器测试、完整分发消费验证和 npm dry-run 均通过。公共 registry 上传与发布后安装需另行验证，不能用本地验证代替发布成功状态。

浏览器测试在 Linux 独立 Chromium 配置中运行。本机缺少的运行库通过临时目录加载，中文字体安装到用户字体目录，不改变应用依赖。构建存在 Zod 上游注释注解提示，不影响构建结果或浏览器运行。

这些验证是功能验证，不是 10 人持续高负载或公网延迟测试。
