最小游戏

一个固定逻辑画布内的收集小游戏：方向键/虚拟方向按钮移动，点按设置目标，碰到道具增加分数；倒计时结束进入结算。复用现有精灵、帧动画、矩形/圆碰撞，反馈使用基本缓动和音效。无需复杂物理、骨骼或地图编辑器。

页面为首页、关卡选择、游玩、设置与结算。游戏页使用 GameCanvas 和独立 HUD；暂停面板留在游戏页内，设置页离开游戏是否保留进度由共享 GameStore 显式决定，不能靠页面未销毁泄漏活动来保留。

提供两套小型开发者主题，至少替换暂停/设置按钮和一种 Canvas 道具图标。资源由仓库内明确许可的最小素材提供，不要求下载外部主题服务。普通图片与图集替换都走同一语义键；音频默认受静音/音量控制并处理未解锁状态。

保存在白名单内的高分、关卡进度、音量/静音等偏好，不保存活动 Entity 或登录凭据。默认单机项目无登录入口；认证/权限另有最小带后端适配的测试示例，不把完整账号产品混入参考游戏。

实施验收矩阵

场景 必须观察到的结果 自动/人工边界
创建与构建 不编辑引擎源码即可生成、check、静态构建 独立项目自动验证
表单与组件 昵称草稿、预览、按钮可用状态联动，model 可复用 Node DOM；输入法体验人工
导航与预加载 代码按页拆分，提前加载不启动游戏，取消不覆盖新页 驱动/静态产物自动；浏览器历史人工
游玩/暂停/重开 单一循环、暂停保留 HUD，离页活动释放 Engine/驱动自动；实际手感人工
主题 配置选择替换 DOM 和 Canvas 图标，碰撞/尺寸契约不变 解析/逻辑自动；真实画面人工
资源与音频 进度/失败可见、解锁后播放、静音偏好保留 注入 Driver 自动；设备播放人工
保存恢复 合法数据恢复、坏档不静默删除、页面私有状态不串 存储适配自动
交付 vendor 相对依赖、公开入口类型/执行、无意外服务端依赖 tgz 外部消费自动

Node DOM 和静态构建不算通过真实浏览器游玩。人工未执行时在验证记录中保留“未验证”；不把任务列表全部勾选为发布就绪。只有相关授权到位才进行对应浏览器操作。

开发体验记录

对“新增页面、复用组件、替换一套图标、加一个动作、保存一个偏好”各记录修改文件、手工同步/监听及诊断位置。应能沿业务目录完成，不依赖复制 AppState、改框架内部、拼接 chunk 地址或重复创建清理逻辑。

性能只对该参考游戏记录构建体积、选定设备/场景、实体规模和帧/内存数据；没有测量前不写更快、更轻或支持任意规模。GPU/复杂物理需求由真实测量另开任务，不挡当前小型 2D 闭环。
